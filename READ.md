## ✨ Features

- 🔗 **Wallet Connection Simulation** – Connect/disconnect mock wallet (MetaMask style)
- 📦 **Simple Blockchain Visualization** – View blocks, hashes, and chain integrity
- ⛏️ **Mine New Blocks** – Add custom data to create new blocks
- ✅ **Chain Validation** – Check if blockchain is tampered

## 🧠 How It Works

This app simulates a basic blockchain with:
- Each block contains: index, timestamp, data, previous hash, and its own hash
- Proof-of-Work difficulty (adjustable)
- Tamper-evident design – changing any block breaks the chain
